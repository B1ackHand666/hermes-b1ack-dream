# Hermes B1ack Dream provider

This directory is the official Hermes Memory Provider plugin. Hermes discovers it as `b1ack-dream`, starts its bundled local runtime automatically, and stores all plugin data at `<HERMES_HOME>/b1ack-dream/`.

It intentionally does not synchronize Hermes `memories/USER.md` or `memories/MEMORY.md`. The optional editor is disabled by default and requires explicit confirmation for every write.
